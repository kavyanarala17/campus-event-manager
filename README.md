## 🎓 Campus Event Manager

A modern Flutter-based Smart Campus Event & Participation Management System designed for colleges and universities.

This application helps students join events easily and allows admins to manage events and monitor participant details in real time.

---

### 🚀 Features

#### 👨‍🎓 Student Features

- View all upcoming campus events
- Search events instantly
- Join events using detailed registration form
- View participant count updates live
- Like/Favorite events
- Modern responsive UI

---

#### 👨‍💼 Admin Features

- Add new events
- Monitor joined students
- View student details:
  - Name
  - USN
  - Branch
  - Year
- Track participation statistics
- Event management dashboard

---

### 🎨 UI Highlights

- Modern gradient dashboard
- Interactive progress bars
- Responsive event cards
- Dark mode support
- Clean Flutter UI
