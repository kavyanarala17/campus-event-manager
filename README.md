# 🎓 Campus Event Manager

A modern Flutter-based Campus Event Management App where students can join events and admins can manage them easily.

---

## ✨ Features

### 👨‍🎓 Student Features
- Login as Student
- View Events
- Search Events
- Join Events
- Like/Favorite Events
- View Seats Remaining

### 👨‍💼 Admin Features
- Add New Events
- View Joined Students
- Track Participants
- Monitor Event Filling

### 🌙 Additional Features
- Dark/Light Mode
- Local Data Storage
- Gradient UI
- Responsive Design

---

## 🛠️ Technologies Used
- Flutter
- Dart
- SharedPreferences
